# 西幻女性衍生版数据模型

Fantasy v1.0 采用约 70% 日式轻小说角色表现与 30% 传统西幻角色骨架。公开作品只用于观察分类方式；网页中的名称、能力和组织全部采用通用化原创表达。

## 生成依赖

```text
世界风格 + 稀有度 ─> 种族 ─> 姓名文化、外貌、身高、种族限定诅咒
世界风格 + 稀有度 ─> 职业 ─> 战斗定位、武器、护甲、魔法、职业限定代价
出身 ─> 社会身份与成长经历
正向性格 ─> 兼容负面性格
可选开关 ─> 身体痕迹、诅咒/魔力代价、异色瞳
全部设定 ─> 称号、剧情钩子、四种绘图模型提示词
```

## 池规模

- 18 种种族，包括人类、精灵亚种、矮人、半身人、兽人亚种、龙裔、魔裔、天裔、夜血族、妖精、海裔、人造生命与元素灵裔。
- 40 类出身，覆盖平民、贵族、教会、学院、军旅、商贸、部族、流亡与遗迹背景。
- 30 个职业，覆盖前卫、游击、远程、施法、支援、制造和非战斗型身份。
- 24 个正向性格、38 个负面特质、18 个身体痕迹、16 个诅咒/代价及 30 个剧情钩子。

## 兼容原则

1. 身高只在所选种族的成年女性范围中产生。
2. 武器、护甲与魔法只从当前职业档案抽取。
3. 负面特质必须避开全部正向性格声明的冲突键。
4. 带 `species` 限制的诅咒只能赋予对应种族；带 `groups` 限制的代价只能赋予相应职业组。
5. 稀有种族与职业按世界风格和稀有度调整权重，而非简单开启或关闭。
6. 标签模型提示词只输出英文映射；GPT Image 使用完整英文创作简报。

## 调研抽象

日式异世界作品中常见的“冒险者职业、上级职、种族、称号、队伍定位、特殊魔法、组织身份和反差性格”被抽象为独立字段；传统奇幻的“种族、背景、职业、装备”则用于约束字段之间的关系。这样既保留轻小说式辨识度，也避免无规则堆叠稀有血统、神器与能力。
