# 现代女性人设 Roll 机

一个零依赖、零后端的现代 ACGN 女性人设随机生成器。打开网页即可生成姓名、身材、发型发色、瞳色、身体数据、肤色、穿搭、鞋袜配饰与融合性格。

## 当前版本

- 版本：Modern v1.0
- 默认角色：成年女性（18+）
- 运行方式：纯 HTML / CSS / JavaScript
- 数据保存：访客自己的浏览器 `localStorage`
- 后端与数据库：不需要

## 功能

- 中式、日式、西式姓名体系
- 三种成年女性体型及相关区间身体数据
- 纯色、染色发色与协调色板
- 根据头发长度选择兼容发型
- 纯色瞳与协调异色瞳
- 多种现代、ACGN 与日系穿搭档案
- 鞋、袜、配饰与服装联动
- 2–3 个无直接冲突的融合性格标签
- 单项重抽、锁定、复制人设与 JSON 导出
- 响应式布局和本地状态保存

## 直接使用

双击根目录的 `index.html` 即可运行。

部分浏览器会限制 `file://` 页面使用剪贴板。需要模拟线上环境时，可以在仓库根目录运行：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。

## 修改随机池

所有数据都在 `index.html` 的 `<script>` 中，主要常量包括：

- `NAMES`：姓名库
- `BODY_TYPES`：体型及身体数据区间
- `HAIR_LENGTHS`：长度与发型池
- `HAIR_COLORS`、`DYE_PAIRS`：纯色与染发配色
- `EYE_COLORS`、`HETERO_EYES`：瞳色
- `SKINS`：肤色
- `OUTFITS`：服装、鞋袜和配饰档案
- `PERSONALITY_LAYERS`：性格标签及冲突关系

修改后至少执行一次 JavaScript 语法检查，并在桌面与窄屏浏览器中各生成数次结果。

## 发布

## 隐私与安全

- 当前版本不上传或集中保存生成记录。
- 不要把 API 密钥、账号凭证或 `.env` 文件写入 `index.html`。
- 如果未来需要调用带密钥的 AI API，应增加后端或服务端函数，不能把密钥放在前端代码中。
